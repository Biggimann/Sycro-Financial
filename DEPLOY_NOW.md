# Sycro Financial — Deploy the Existing Render Service

This package is a complete replacement for the current repository.

## Do NOT create another Render service or repository.

Replace the files in the existing GitHub repository with the contents of this package.

Repository root must contain `app.py`, `requirements.txt`, `Procfile`, `render.yaml`, `templates/`, and `static/`.

## Render

Service: Web Service
Plan: Free

Build:
`pip install --no-cache-dir -r requirements.txt`

Start:
`gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 2 --timeout 90 --max-requests 500 --max-requests-jitter 50 app:app`

Health:
`/health`

Environment:
`SECRET_KEY` can be generated by Render.
`DB_DIR=/tmp/sycro`

After GitHub receives the replacement files, Render should automatically deploy the new commit if auto-deploy is enabled.

Test:
`https://YOUR-SERVICE.onrender.com/health`

Expected:
`{"status":"ok"}`

## Free-plan database limitation

SQLite is stored in `/tmp/sycro` because Render Free has no persistent disk. Data can reset after a restart/redeploy. For durable data later, migrate the app to PostgreSQL.
